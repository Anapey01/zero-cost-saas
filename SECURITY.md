# Security Policy

## Reporting Security Vulnerabilities

We take security and responsible disclosure seriously.

If you believe you have discovered a security vulnerability or sensitive information disclosure in this repository:

1. **Do NOT open a public GitHub issue or pull request.**
2. Please report the issue privately using [GitHub Security Advisories](https://github.com/Anapey01/zero-cost-saas/security/advisories/new).
3. If Security Advisories are unavailable, contact the maintainer directly via their GitHub profile.

Please include:
- A clear description of the issue
- Steps to reproduce or a proof of concept
- Potential impact and mitigation recommendations

We appreciate your assistance in keeping this project secure.
